# 🎯 Тренажёр для подготовки к контрольным

Сайт для группы: практики по любым предметам, интервальные повторения, режим контрольной и редактор, в котором любой может собрать свою практику и отправить её ссылкой.

**Сайт:** https://alukkart.github.io/trainer/

Сервер и сборка не нужны: это обычные HTML, CSS и JS.

## Запуск

- **Локально:** откройте `index.html` двойным кликом. Всё работает, включая запуск Python-кода (нужен интернет, чтобы один раз загрузить Python и библиотеку формул).
- **Для всей группы (бесплатно):** выложите папку на GitHub Pages.
  1. Создайте репозиторий на GitHub и загрузите туда все файлы.
  2. Откройте Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
  3. Через минуту сайт будет доступен по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.

  Подойдёт и любой другой статический хостинг: Netlify, Vercel, Cloudflare Pages.

## Что умеет

| Тип задания | Для чего |
|---|---|
| Выбор ответа | тесты, один или несколько правильных вариантов |
| Ввод ответа | слово или фраза, допускается несколько вариантов ответа |
| Число / выражение | математика и физика: дроби, выражения, несколько корней, погрешность; **генератор задач со случайными числами** |
| Пропуски в тексте | грамматика, пропущенные слова, выпадающие списки, банк слов, пропуски в коде |
| Расставить по порядку | порядок слов в предложении, шаги алгоритма, хронология |
| Сопоставление пар | слово ↔ перевод, термин ↔ определение |
| Карточка | запоминание с самооценкой «помню / не помню» |
| Программирование | Python и JavaScript запускаются в браузере и проверяются тестами; для C++, Pascal и других языков есть самопроверка по эталону |

Режимы: **тренировка** (ошибки повторяются в конце), **интервальное повторение** (по системе Лейтнера), **работа над ошибками** и **контрольная** (с таймером и оценкой).
В тексте заданий работают формулы LaTeX (`$x^2$`), разметка, код и картинки.

Прогресс хранится в браузере каждого ученика (localStorage).

## Как добавлять практики

**Способ 1: через сайт.** Нажмите «＋ Создать», заполните задания, затем «🔗 Поделиться» и отправьте ссылку в чат. Практика целиком хранится в самой ссылке.

**Способ 2: постоянно на сайте.** Положите файл практики в папку `practices/` и добавьте его имя в `practices/index.js`:

```js
Trainer.add({
  id: 'history-ww2',            // уникальный, латиницей
  title: 'Вторая мировая война',
  subject: 'История',           // по этому полю группируются карточки на главной
  tasks: [
    { type: 'choice', q: 'Когда началась война?', options: ['1939', '1941'], answer: '1939' },
    { type: 'gaps', text: 'Битва под [Сталинградом] закончилась в [1943] году.' },
    { type: 'flashcard', front: 'Дата открытия второго фронта', back: '6 июня 1944' },
  ],
});
```

Готовый файл можно скачать из редактора кнопкой «Файл .js». Полное описание формата со всеми полями и живыми примерами открывается на сайте в разделе **«Справка»**. Готовые практики в папке `practices/` тоже служат примерами.

## Структура

```
index.html          — страница
css/style.css       — оформление (светлая и тёмная тема)
js/util.js          — утилиты, markdown, хранилище, шаринг ссылкой
js/mathexpr.js      — безопасный калькулятор выражений и генератор переменных
js/runner.js        — запуск кода (JavaScript в Web Worker, Python через Pyodide)
js/tasks.js         — типы заданий: новый тип добавляется здесь
js/player.js        — прохождение, интервальные повторения, результаты
js/editor.js        — визуальный редактор
js/app.js           — главная, страница практики, маршруты
js/help.js          — справка
practices/          — практики сайта
```
